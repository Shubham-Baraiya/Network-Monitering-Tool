# Network Monitoring Tool

## Computer Networks PBL Micro Project

A Python-based network monitoring application developed for the
Computer Networks PBL activity.

---

## Features

### Mandatory Modules

- C1 - Interface Traffic Monitor
- C2 - Local Subnet Host Discovery
- C3 - Reachability and Latency Monitor
- C4 - Traffic Composition Analyzer

### Extensions

- E3 - Historical Logging and Charting
- E5 - Auto-refreshing Dashboard

---

## Technologies

- Python 3
- psutil
- Scapy
- Flask
- Matplotlib
- CSV
